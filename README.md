# ترحال (TERHAL)

المستودع الجاهز لتسليم تحديث تطبيق ترحال على Android وiOS، ويشمل سورس Flutter والباك إند وملفات النشر الضرورية فقط.

- تعليمات إصدار المتاجر: [STORE_RELEASE.md](STORE_RELEASE.md)
- تطبيق Flutter: `mobile/`
- باك إند Django: `backend/`
- إعدادات النشر: `deployment/`
- APK جاهز للاختبار: `dist/Terhal-1.3.0+6.apk`

إصدار التطبيق الحالي: `1.3.0+6`.
